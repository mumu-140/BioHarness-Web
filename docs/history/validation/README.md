# Validation record index

The validation records currently in this directory belong to the former BioHarness-Web read-only Observatory V1. They document V1 graph readability, attempt context, execution history and evidence-preview behavior.

They do not establish V2 readiness and must not be used as V2 acceptance evidence.

V2 acceptance is defined in [the active Research Workspace plan](../../plans/2026-11-25-research-workspace-v2.md). New V2 evidence must identify the exact Web, Core and Module versions used, distinguish UI/runtime contract tests from scientific evaluation, and retain source-backed evidence.
